# Benchmarks (measured, not estimated)

Machine: Windows 10 Home 19045, x86-64, 16 logical cores, 32 GB RAM, SSD. Rust 1.100.0 release profile (thin LTO). CPU only. Data: synthetic CC0 images generated by `crates/pipeline/examples/rich_fixture.rs` and `crates/edit/examples/bench_color.rs`. Three runs each; medians reported. Reproduce with the commands shown.

## Command-line operations (1600 x 1067 PNG, 3.0 MB)

`photo-defense <command>` wall time including process start-up:

| Operation | Median |
|---|---|
| `inspect` (bounded decode + SHA-256 + BLAKE3) | 66 ms (first cold run 275 ms) |
| `scan --profile Cybersecurity` (metadata, tiled QR/barcode detection, text rules) | 385 ms |
| `process --auto-redact --aspect 4:5` (scan, redact, crop, encode, reopen, verify, publish) | 626 ms |

## Colour adjustments (`cargo run --release -p photo-edit --example bench_color`)

| Image | Per-pixel layer (exposure, contrast, HSL, white balance) | Same plus clarity, sharpening, noise reduction |
|---|---|---|
| 1600 x 1067 (1.7 MP) | 72 ms | 557 ms |
| 4000 x 3000 (12 MP) | 502 ms | 3905 ms |
| 6000 x 4000 (24 MP, maximum accepted) | 1012 ms | 7736 ms |

The per-pixel stage runs on all cores. Detail operations use single-threaded Gaussian blurs from the `image` crate; clarity was made about 28% faster in this increment by blurring a downscaled copy for wide radii (before: 757 ms / 5226 ms / 10721 ms). Interactive editing renders a proxy of at most 1600 px, so the 1.7 MP row is the interactive cost; full-resolution cost is paid once at export.

## Desktop (debug build, observed in the Performance Center)

Proxy preview render without edits: about 290 ms (debug). Privacy Scan of 1600 x 1067: about 2.8 s (debug). Release figures for the desktop's background tasks match the CLI rows above because they call the same functions.

## Not measured

- Competitive benchmarks against darktable, RawTherapee, GIMP, ImageOptim, Graphite, Lightroom Classic, Capture One or Affinity Photo: **not performed**. None were installed or licensed on the test machine, and no common RAW test set was available. No comparative claim is made.
- GPU utilisation: no GPU code path exists.
- Privacy detection precision/recall: no labelled dataset (see TESTING.md).
- Adversarial protection effectiveness: no validated protection exists.
- 8 GB RAM systems: not available for testing.
