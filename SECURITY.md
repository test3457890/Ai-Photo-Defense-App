# Security policy

This pre-1.0 development preview is not approved for production protection claims or release distribution. Review [the threat model](docs/THREAT_MODEL.md) and [current security review](docs/SECURITY_REVIEW.md).

Report a suspected vulnerability privately through this repository's GitHub Security Advisories reporting feature if enabled. If that feature is unavailable, open an issue asking the maintainer for a private reporting channel without posting exploit details, personal photographs or credentials. No response-time SLA is established yet. Avoid public uploads of sensitive test images.

Supported security updates currently target the active development branch only. No signed update service or stable release exists. The application does not auto-update or download/execute model code. Dependency alerts and audit checks must pass, with documented triage of informational warnings, before a release candidate is approved.
